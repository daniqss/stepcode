# stepcode

## Getting started

**stepcode** is a tool for generating static books with support for step-by-step pseudocode execution.

In this example book we are going to cover the specification of our pseudocode implementation so you can implement you own
to teach students or to learn using it as a playground.

## Chapters

We support the following constructs:

1. [Variables](./chapters/1-variables.html)
2. [Conditionals](./chapters/2-conditionals.html)
3. [Loops](./chapters/3-loops.html)
4. [Functions](./chapters/4-functions.html)
